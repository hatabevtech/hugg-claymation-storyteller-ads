# hugg-claymation-storyteller-ads

Production repo for hugg's claymation mechanism ads (Meta, 9:16).

- **Run in:** a Claude Code session at claude.ai/code, environment **Gemini + Ads** (Gemini API key attached as a network secret).
- **Start a session with:** "Read CLAUDE.md and storyboard.md, test the Gemini API, then generate batch 1 (S01–S02)."
- **Current ad:** TumGard × H. pylori, "Bacteria gaya, nuksaan wahi raha". The source storyboard is `claude/12_tumgard_hpylori_animated_storyboard.md` in the claude.ai project "Objective: Launch Better Ads".

| Folder | Contents |
|---|---|
| `cast/` | Locked cast sheet: Rohan, H. pylori, lining states, props, jar |
| `prompts/` | Exact prompt used for every shot |
| `frames/` | Generated options; `frames/final/` holds approved keyframes |
